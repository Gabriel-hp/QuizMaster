##🎯 QuizMaster


QuizMaster é uma plataforma web de simulado para concursos e provas, desenvolvida com Laravel e MySQL, que permite aos usuários praticar com questões de diversas categorias como Português, Informática e Raciocínio Lógico.

🚀 Funcionalidades

🎓 Simulados personalizados

Escolha a quantidade de perguntas

Filtro por categoria e tema

📊 Página de resultados com pontuação final

🧠 Banco de questões atualizado com temas como FGV, concursos públicos e TI

💡 Design limpo e responsivo, com foco na legibilidade

🔐 Sistema de autenticação com Jetstream (Livewire)

🛠️ Tecnologias Utilizadas

Laravel 11

PHP

MySQL

HTML/CSS/JS

Jetstream com Livewire
